The first explainer shown in the Teach view was the classroom-screen preview. That preview deliberately had `inert` and `pointer-events: none`; it looked like the original interactive document, but its Play buttons, sliders, and quiz choices could not be operated. The actual teacher controls were below the preview and the full notes/action panel.

For original Claude explainers, Command Center now places the full-width **Interactive explainer** first. Its controls update the existing presentation session. It opens for a classroom activity; the controller remains mounted so returning preserves its state. Daily decks and other teaching tools retain their existing presentation layout.

The source HTML, CSS, animations, quizzes, and runtime remain unchanged. No database schema, lesson publication, student response, or mastery changes are made.
