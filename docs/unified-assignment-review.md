# Unified assignment review

Results → an **awaiting review** button opens the shared review desk. The left rail shows names only. The assignment selector also exposes native activities contained inside a choice menu.

The focused workspace displays **one response at a time**. Numbered response buttons show entered rating colors and revision markers; previous/next controls keep every response reachable without losing edits. Antocci rationale, suggested feedback, answer guides and response feedback expand on demand. The right panel keeps the calculated grade, all final mastery decisions and overall feedback together. Missing-score links select the required response before focusing its point field; four-dimension rubrics and separate score items remain in the final-review panel. Keys 1–3 rate the active response when focus is in the evidence panel and outside an editable field.

The persistent action bar offers Save draft, Request revision, Preview release and **Mark ready & next**. Mark ready saves through the existing validated private-draft endpoint, then advances to the next awaiting review that has not already been marked ready. It does not release feedback or grades. Manual student/assignment navigation retains the unsaved-change guard. Revision history and previous/current responses are expandable; the changed-response filter remains available.

Each submitted evidence item shows an advisory **Antocci suggests** rating and feedback. A click adds feedback without replacing teacher writing. Evidence uses 1 Not yet (red), 2 Almost (yellow), 3 Got it (green), and an explicit insufficient-evidence option. After the teacher reviews every evidence item linked to a target, a combined suggestion averages their entered numeric ratings and rounds to the nearest 1–3 level. “No new rating” items are excluded. The calculation and evidence count are visible; a teacher must explicitly approve the suggested final mastery. It never changes a final decision automatically or converts mastery into percentage points.

New reviews prefill valid available suggested point scores. Saved reviews restore their exact values, including zeroes and deliberately cleared fields. The overall percentage updates from earned points divided by authored possible points. A score-completion checklist identifies missing or invalid scores and jumps to the field; “Use remaining suggested scores” fills blanks without replacing existing entries. Evidence ratings and point scores remain clearly separate.

**Apply all suggestions** fills only empty scores, evidence ratings, final mastery decisions, response/dimension feedback, and overall feedback. Existing writing, zero scores, explicit “No new rating,” letter/credit decisions and already released mastery are preserved. Unfilled final mastery uses combined evidence ratings when available, otherwise the valid Antocci target suggestion. This explicit action updates only the private editor; the teacher reviews and edits it before saving or previewing release. Suggestions that arrive later can be applied with the same button without replacing earlier entries.

Authored quiz points, daily review scores, four-dimension lab/transfer grades, vocabulary formats and math mastery retain their original rules and release endpoints. Math has no percentage grade. Supported math corrections are acknowledged and lead to a fresh independent check. Paper work records completion through its existing controls. Vocabulary checkpoints and missions use fresh reassessment rather than reopening immutable attempts. Choice attachments remain inspectable through the existing authorized file endpoint.

Save draft keeps decisions private. Mark ready adds the saved version to the release queue. Individual and selected batch releases show the exact saved grade, mastery and feedback first. Stale submissions, concurrent draft changes and native review changes reject the release. Interrupted releases retain their frozen plan and support retry; original source ledgers remain authoritative.

Request revision sends the overall next step plus response-specific feedback without a new grade or mastery score. Students read the feedback, edit their existing assignment, check the feedback items, save a change summary, then use the assignment's Submit button. Returning revisions have a purple label, change summary, previous/current responses and a changed-response filter. Released feedback appears on the student's assignment.

The additive migration creates three server-only, RLS-enabled tables for drafts, revision receipts and suggestions. Existing attempts, ratings, grades, student answers and released feedback are preserved. AI suggestions and private drafts are not exposed by the student endpoint.

Verification uses fictional fixtures for the actual review components and API handlers, source adapters/action plans, scoring rules, stale-state rejection, interrupted-release recovery and privacy. PostgreSQL checks exercise the actual migration, grants, row-level security, compare-and-swap updates and release leases. No real student grades are released as part of testing.
