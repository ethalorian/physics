## Answers and what to listen for

**STOP 1 · Predict.** Before release, Σp = 0 (both at rest). After, Σp must still be 0, so the momenta are equal and opposite: the **1 kg cart moves 3× faster** than the 3 kg cart. The film uses 3 m/s west and 1 m/s east: (1)(−3) + (3)(+1) = 0. The spring's pushes are internal forces between the carts, so they cancel in the total.

**STOP 2 · Your turn (skater).** System: skater + ball, on ice (negligible friction, so negligible external impulse). East = +.
0 = (5)(+8) + (70)v → v = −40/70 ≈ **−0.57 m/s**, i.e. **0.57 m/s west**.

**STOP 3 · Group practice.** For each problem: define the system, state whether any external impulse is negligible, then set Σp before = Σp after. Rocket: system = rocket + exhaust; gas pushed backward gives the rocket equal forward momentum.

**STOP 4 · Exit ticket.** East = +. Before: Σp = 0. After: (0.3)(+12) + (0.2)v = 0 → v = −3.6/0.2 = **−18 m/s**, i.e. **18 m/s west**.

**STOP 5 · Marzano on K3.** The closing line links to DART: in the spacecraft + asteroid system, the spacecraft lost momentum and the asteroid gained it.

## Formative checks
- Students name a system that contains **both** interacting objects.
- They state the condition (no net external force, or negligible external impulse) **before** using conservation.

## Next teaching move
Sort exit tickets for a missing minus sign (18 m/s with no direction), using only one object as the system, or setting the *speeds* (not momenta) equal. Open next class with the spring carts and a system box drawn around just one cart: is momentum conserved for that system? Why not?
