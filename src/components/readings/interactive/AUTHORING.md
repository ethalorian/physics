# Connected textbook authoring

The HTML readers are original instructional adaptations aligned to the two source textbooks. They preserve source section identities and links; they do not claim to reproduce every publisher paragraph, photograph, supplementary example, or numbered exercise. The complete PDFs remain available.

## Current scope

Core English adaptations: Hewitt 2–40 and OpenStax 1–34: all 73 source chapters and 551 sections have core English instructional adaptations. Complete source PDFs remain available for detailed publisher artwork and exercises. Spanish and Portuguese readers retain their existing PDFs.

The original app checkout is the source of truth. Update it with each verified batch, synchronize the isolated release copy, and deploy only the reviewed textbook files. Preserve unrelated changes in the checkout. The release manifest records source hashes and the deployment baseline.

## One reader and one assignment contract

`InteractiveChapterReader` owns navigation, larger text, resume position, private notes, ungraded checks, inline assignment slots, and review-area presentation. `ReadingStudentWork` owns graded responses and the authenticated, versioned save and submission workflow. Never duplicate that state in a chapter module.

`lesson-contract.ts` defines section content and the chapter factory. `ConnectedChapterReader` renders these lessons through the shared reader. `connected-chapter-catalog.ts` registers the renderer and metadata together. Hewitt Chapter 2 retains its dedicated implementation. `registry.ts` selects HTML only when every requested section of the primary source is covered in the requested language. OpenStax assignments spanning chapters keep the existing PDF presentation until the registry supports a combined reader.

Keep book identity, chapter, section number, printed page, PDF offset, language, content version, and section ID explicit. Preserve stable IDs and check meanings to retain user-scoped device notes and progress. Change `contentVersion` when old stored responses would otherwise acquire a different meaning.

## Conversion process

1. Read the source and metadata. Inventory learning objectives, concepts, equations, definitions, worked reasoning, numbered illustrations, and exercise groups. Extracted text is evidence for authoring, not a finished chapter. Check missing equation glyphs against a reliable representation.
2. Map every source section explicitly to an authored lesson and page range. Shared explanations can be reused across books only when objectives match; add the quantitative or conceptual depth required by each source. Avoid repeating the same explanation and example across several sections of one chapter.
3. Build each section around a clear question, explanation, purposeful illustration or exploration, vocabulary, a worked example, and a diagnostic check. Give each option useful feedback and a teacher prompt. State signs, units, reference frames, system boundaries, and assumptions.
4. Inventory every numbered in-scope source illustration in `visualCoverage`. Mark a figure adapted only when an actual HTML visual teaches its central relationship. Link that figure to a rendered anchor. Label retained photographs, apparatus details, and supplementary diagrams as PDF-only. Do not claim that an unrelated graphic replaces them.
5. Use deterministic SVG for precise diagrams. State scale conventions and identify physical forces separately from calculated resultants. Provide accessible descriptions, keyboard controls, and readable numerical results. Put equations in pure model functions when needed and test conservation, units, boundaries, and limiting cases.
6. Map question references conservatively. Exact source section references can be placed inline. Only map numbered concept checks after verifying their source group boundaries. Unverified or custom references remain in the final assignment-review area; never map a Hewitt exercise to an OpenStax section by number alone.
7. Verify all source links, chapter eligibility, unique anchors, diagnostic feedback, and target mappings. Check desktop and phone layouts, larger text, keyboard navigation, retry behavior, and browser errors. Test the native assignment flow when the reader or integration changes: save, reload, failure/retry, submit, quiz unlock, teacher feedback, revision, and immutable history.
8. Run focused tests, TypeScript, lint, and required audits. Use disposable records for database checks. Stage the reviewed files on the existing Vercel project, verify the build and new routes, and publish the verified deployment. Record any unverified acceptance step explicitly. A public sign-in screen does not prove an authenticated classroom walkthrough.
9. Update the conversion inventory, source package, release manifest, and original checkout. A teacher content review remains useful; do not label unreviewed extracted material ready merely to improve the chapter count.

## Connected learning and mastery

The existing reading syllabus prepares four linked drafts: reading, vocabulary practice, reading quiz, and vocabulary quiz. Preparation is idempotent per class and syllabus step and reuses canonical vocabulary and real target IDs. The teacher reviews the drafts and releases work using existing controls. Merely opening a chapter does not create assignments or duplicate a bundle.

Publishing a syllabus step releases its reading, vocabulary practice, and reading quiz. The vocabulary quiz stays a teacher-controlled draft until separately published. Reading submission unlocks the reading quiz for that student. `ReadingLearningPath` uses the student-safe syllabus API, hides unpublished draft links, and updates access from the submission response. Navigation saves outstanding responses first; a failed save leaves the student with their work.

Reviewed reading responses and explicit teacher decisions on quiz evidence feed the existing target-level mastery transactions. Practice checks, scrolling, private notes, and elapsed reading time do not award mastery. Browse mode clearly identifies its sample learning sequence; custom readings outside the syllabus do not automatically acquire a four-assignment bundle.

The release manifest records the current count of existing syllabus assignment variants that select HTML. All 64 syllabus steps validate for both tracks. This count measures supported existing assignments, not newly published student work.

## Supplemental source verification

The black-hole adaptation corrects the older source’s oversimplified stellar-remnant discussion: the Sun becomes a cooling white dwarf, not a black hole. The same-mass, fixed-external-radius comparison is explicitly conditional. Verified against [NASA’s black-hole questions](https://science.nasa.gov/universe/10-questions-you-might-have-about-black-holes/) and [NASA’s explanation of the Sun’s future](https://www.nasa.gov/image-article/why-sun-wont-become-black-hole/). Historical textbook energy, habitat, and satellite examples are not presented as current project specifications.

The relativity adaptation uses invariant mass, distinguishes proper time from signal-arrival effects, and avoids a photon rest frame. The atomic chapter uses the [IUPAC periodic table](https://iupac.org/what-we-do/periodic-table-of-elements/). The gravity chapter updates the old pre-detection account using [LIGO’s first detection](https://www.ligo.caltech.edu/detection). Flow explanations reject equal-transit lift and connect pressure to momentum using [NASA’s Bernoulli and Newton explanation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/bernoulli-and-newton/). These sources are linked in the relevant student sections.

The original 64-step syllabus remains available. The section-based template catalog supplements it with every converted section. Custom readings prepared outside either sequence do not automatically acquire linked vocabulary and quizzes.


## Section assignment sequences
Every registered section now exposes a teacher-only template in `src/data/textbook-syllabus.ts`. Terms come from that section; the reading response anchors beside it, and the reading quiz asks students to change a condition and transfer the idea. New templates require explicit reading and Knowledge vocabulary targets from the same curriculum unit. Do not invent target IDs or silently map a new topic to an unrelated target. OpenStax retains the Honors course restriction. The existing transactional bundle RPC prepares all four drafts, reuses accessible canonical terms, controls release, and gates the reading quiz by submission. Mastery requires teacher review.

Validate new registrations with `node scripts/test-connected-textbook-bundles.cjs`, the conversion test, model tests, and the existing syllabus/reading Postgres regression scripts. The 2026-10-12 thermal release adds Hewitt 21–24 and OpenStax 13–15 (51 sections), 27 original model types, and 164 source-figure inventory entries.

The waves and sound release adds Hewitt 25–26 and OpenStax 16–17: 39 sections, 19 original model types, and 128 numbered source illustrations. The source comparisons distinguish mechanical propagation from local particle motion, sound speed from frequency, pressure from displacement, weak-disturbance Mach geometry from real boat wakes, and ideal resonance from structural feedback. Hearing uses NIDCD evidence; ultrasound uses FDA evidence and does not imply that non-ionizing means risk-free.

The light release adds Hewitt 27–28 and OpenStax 24: 23 sections and 68 inventoried source illustrations. Original models distinguish field amplitude, intensity, and photon energy; conserve reflected/transmitted/absorbed energy; handle the zero-umbra limit; and identify ideal display-color assumptions. Transparency is wavelength-specific, not a claim that all glass blocks all infrared or ultraviolet. Solar spectra specify wavelength axes and normalization. Historical blanket statements about penetration and microwave resonance are replaced by interaction-dependent explanations.

The geometric-optics release adds Hewitt 29–30 and OpenStax 25–26: 33 sections and 129 individually inventoried source illustrations. Original interactive models cover reflection, Snell refraction and total internal reflection, minimum-deviation prism trials, the primary rainbow, thin-lens and curved-mirror image formation, the fixed-retina eye model, microscope image chains, and telescope angular magnification. Models declare their scales and approximations, distinguish actual rays from virtual extensions, and handle the focal-plane limit without a finite image. Source figures whose detailed apparatus, anatomy, photographs, or constructions are not recreated remain explicitly PDF-only.

The wave-optics release adds Hewitt 31 and OpenStax 27: 16 sections and 81 source illustrations inventoried individually. Field superposition is distinguished from intensity addition, coherent laser beams retain finite diffraction, and Rayleigh resolution is a criterion with stated source assumptions. Models cover single and double slits, multiple-slit array factors, Airy profiles, lossless thin-film reflectance with reflection phase, Gaussian-beam spreading, one-dimensional hologram encoding, Brewster geometry, ideal polarization rotation, and phase-to-intensity contrast. Source claims that every microscopic detail smaller than a wavelength is impossible to measure, or that coherent beams never spread, are not carried into the adaptation.

The electrostatics release adds Hewitt 32–33 and OpenStax 18–19: 29 sections and 93 numbered source illustrations. Original models distinguish charge transfer from polarization, test force from source field, scalar potential from vector field, and fixed-voltage from fixed-charge capacitor changes. Series/parallel networks conserve the appropriate node charges and voltage sums. Lightning protection descriptions follow the National Weather Service and do not repeat the sources’ claim that lightning rods prevent strikes. Molecular dielectric comparisons are explicitly limited and do not predict biological binding energies.

The current and circuits release adds Hewitt 34–35 and OpenStax 20–21: 31 sections and 101 numbered source illustrations. Models distinguish charge conservation from energy transfer, drift from signal speed, signed AC mean from RMS heating, ideal voltage sources from internal resistance, and current reference arrows from solved directions. Meter loading, a Wheatstone null, and RC charge/discharge are explicit. Safety descriptions avoid the source texts’ guaranteed-safe current/voltage claims and follow OSHA’s distinction between overcurrent and ground-fault protection. Biological waveforms are schematic educational models, never diagnostic tools. Hewitt 35.5 has no numbered Check Concepts group; do not invent one.

The magnetism and induction release adds Hewitt 36–37 and OpenStax 22–23: 40 sections and 134 numbered source illustrations. Charge sign, field orientation, loop normal, conventional current, Hall voltage polarity, and Lenz-law flux-change signs are explicit. Models distinguish constant flux from emf, static inductor energy from induced emf, RMS from instantaneous quantities, and mechanical input from magnetic steering. Modern SI definitions, geodynamo/reversal descriptions, MRI context, and electrical protection descriptions use linked primary references rather than repeating outdated source claims. Do not describe electron spin as literal surface rotation, neutral as safe to touch, a GFCI as universal shock prevention, or constant flux as induction. The full PDF retains nonuniform-field applications, source photographs, and supplementary apparatus details.

The foundations and relativity release adds OpenStax 1 and 28: 10 sections and 48 numbered source illustrations. New explorations distinguish bias from spread, stated bounds from statistical uncertainty, exact conversion factors from measurements, coordinate simultaneity from signal arrival, signed velocity from speed, and invariant mass from frame-dependent energy and momentum. Current SI definitions link to BIPM. Relativistic clock, ruler, and reunion models reuse the established Hewitt explanations where objectives match, with explicit OpenStax quantitative additions and source mapping.

The quantum and atomic release adds OpenStax 29–30: 17 sections and 83 numbered source illustrations. Models distinguish excitation energy from ground-state offsets, optical power from photon energy, single-photon thresholds from nonlinear processes, coherent amplitudes from probabilities, state spreads from instrument errors, Bohr energies from modern orbital states, and state capacity from ground-state filling. Energy–time uncertainty is not permission to violate conservation. Lifetime linewidth is explicitly an exponential-decay FWHM model. X-ray line thresholds and target energies are separate; its spectrum is explicitly schematic. Electron spin is not surface rotation, and the hydrogen ground state has nonzero probability density at the nucleus. Supplemental NIST, Feynman, and FDA sources are linked in the applicable lessons.

The nuclear release adds OpenStax 31–32: 14 sections and 58 individually inventoried source figures. Models separate nuclear identity, activity, detection, dose, and energy conversion. Carbon-14 production uses cosmic-ray-generated neutrons; the weak interaction is not the main nuclear binding force. Tunneling conserves energy, and PET coincidences identify lines rather than unique points. Medical examples teach measurement principles, with current FDA, EPA, and NCI references, not clinical prescriptions. Fusion gain always names its system boundary. Reactor shutdown does not eliminate decay heat. The nuclear weapons adaptation focuses on mechanisms, history, humanitarian consequences, and evidence; it contains no design, yield, or assembly model. Detailed source artwork remains explicitly identified as PDF-only.

The final Hewitt release covers 38–40: 28 sections, 55 individually inventoried numbered source figures, and 15 additional conceptual models. Source Check Concepts ranges were verified from each source chapter. Content distinguishes quantum states from trajectories, deterministic chaos from quantum probabilities, ideal decay ages from calibrated dates, and tracer transport from decay. It corrects dated claims about isotope chemistry, absolute decay constancy, radiation risk, plutonium toxicity, universal reactor enrichment, nuclear binding maxima, and fusion milestones/materials. Isotope enrichment, fuel conversion, and confinement are taught as qualitative concepts, without operating specifications or weapon-design models. Current EPA, NOAA, USGS, and DOE references support targeted corrections. Existing shared lessons are reused where objectives align; source numbering and page links remain book-specific.

The final frontier release completes OpenStax 33–34: 13 sections, 12 new original models, and 50 individually inventoried source figures. Particle conservation accounts include neutral products and distinguish necessary conditions from rates. Yukawa range is an effective model, not energy borrowing. Collision comparisons name their frame and energy budget. Higgs discovery and gravitational-wave detection are established results; unification, fundamental strings, and dark-matter identity remain research questions. Cosmological expansion is not a central explosion. Lensing images are angular positions, not ray paths. Superconductivity includes field/current conditions and magnetic evidence. Complexity is broader than the logistic-map chaos illustration. Source-only photographs and full multi-panel artwork remain explicitly linked in the PDF.
