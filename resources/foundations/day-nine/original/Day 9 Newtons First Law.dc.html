Newton’s first law

In an inertial reference frame, an object at rest stays at rest, and an object in motion keeps the same velocity, unless a nonzero net external force changes that velocity.

ΣF = 0 implies a = 0

Inertia and mass

Inertia is resistance to a change in velocity. Mass measures translational inertia.

With the same net force, a larger mass changes velocity more slowly.

Inertia is a property of the object, not an extra force arrow.
