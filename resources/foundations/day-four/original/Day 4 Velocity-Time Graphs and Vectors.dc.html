A velocity vector has two components

For a vector in a horizontal plane, choose perpendicular x and y axes.

A velocity of +4 m/s east and +3 m/s north is one diagonal motion with both components occurring at once.

|v| = √(4² + 3²) = 5 m/s

The angle needs a reference axis

Let θ be measured counterclockwise from the positive x-axis.

vx = v cos θ
vy = v sin θ

Adjacent component uses cosine. Opposite component uses sine. Use degree mode for an angle in degrees.

Teacher only · notes & materials
Before class
Visual first, trig second.
For CPA students with weak math, trig is a real obstacle. Start with visual decomposition — draw the arrow, measure components with a ruler.
Build to trig only after the visual is secure. Provide a recipe card; no need to derive cos and sin.
The asteroid connection makes vectors the tool for "will it hit us?" — not math homework.
