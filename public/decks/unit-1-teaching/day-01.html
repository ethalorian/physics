Honors Physics / Unit 1 / Day 114 / 22
Explanation and application

A model makes a testable prediction

A model is a simplified description with stated assumptions.

If an object keeps the same velocity, equal time intervals produce equal displacements. We can compare that prediction with new observations.

New position = starting position + change in position

A tiny prediction we can test

Practice data: a cart is at 2 m, 4 m, and 6 m at 0 s, 1 s, and 2 s.

Predict its position at 3 s. State an assumption and an observation that would challenge it.

Honors Physics / Unit 1 / Day 116 / 22
Solution and reasoning

A tiny prediction we can test

8 m, if the cart continues gaining 2 m of position each second.

A new reading of 7 m would challenge the constant-velocity prediction. Check measurement quality and consider a changed motion model.

Honors Physics / Unit 1 / Day 117 / 22
Explanation and application

What a useful explanation contains

Claim: The cart should reach 8 m at 3 s.

Evidence: Position increased by 2 m in each observed second.

Reasoning: If that pattern continues, another second adds another 2 m.

Limit: A new force or an inaccurate measurement could change the result.
