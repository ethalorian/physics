Honors Physics / Unit 1 / Day 36 / 21
Explanation and application

Average velocity and average speed

v̄ = Δx / Δt
Average speed = total distance / elapsed time

Average velocity carries direction. Average speed describes path length covered per second.

An instantaneous velocity describes a particular moment. An average summarizes an interval.

Round-trip rates

Honors Physics / Unit 1 / Day 38 / 21
Solution and reasoning

Round-trip rates

Distance = 12 m, so average speed = 12/8 = 1.5 m/s.

Displacement = 0 m, so average velocity = 0/8 = 0 m/s.

Honors Physics / Unit 1 / Day 316 / 21
Solution and reasoning

A graph-reading error

The point gives position. To find an interval velocity, choose a second point and calculate Δx/Δt. For an instantaneous velocity on a curve, inspect the tangent slope.

Solution and reasoning

Independent graph calculation

Two more seconds change position by −4 m, so x(8 s) = 6 − 4 = 2 m.
