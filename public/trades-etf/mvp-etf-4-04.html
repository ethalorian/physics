P4 · 04 · Measure Current in the Lamp Branch

At the supervised station, insert the meter into one break in the lamp circuit, record current, then restore the detector.

Name: __________________ Date: __________ · 110 minutes

Why this job?

Current measurement requires the circuit’s charge flow to pass through the instrument. This is a different connection from voltage measurement.

Daily kit · one crew

Each student: tape measure, pencil and graph notebook. Per crew: ruler, scissors and masking tape. Detector and teacher-operated meter station: fused current input/range suitable for the kit lamp rating, insulated leads and meter manual. Teacher makes and approves all current-mode wiring.

Finished means

  1. Restored detector and an independently read current measurement.
  2. Series-insertion sketch, A/mA conversion and separate supplied-resistor calculation.

Worked example · practice values

These supplied values teach the method. Build from today’s required plan dimensions; record your own actual test data.

  1. An ideal 30-ohm resistor has 3.0 V across it. Calculate current in amperes and milliamperes using I = V/R.
  2. For a 30-ohm resistor at 3.0 V, I = V/R = 0.10 A = 100 mA.
  3. Do not assume a motor, lamp or LED behaves like a constant resistor across all conditions.

Stop & show

Trace the series path through the meter. State the difference from measuring voltage across a lamp.

Make · 45 minutes · Numbered bench directions

  1. Switch holder OFF and remove the original switch-to-lamp lead.
  2. Teacher connects switch output to the meter current input and meter COM to lamp A, using the actual instrument’s fused rated input.
  3. Teacher inspects the complete loop and selected current range, then permits holder ON with tongue out.
  4. Each student reads and records current. Turn holder OFF before touching any wiring.
  5. Teacher removes meter and restores the original switch-to-lamp lead. Return red meter lead to its V socket for storage.
  6. Run three detector OFF/ON cycles to confirm restoration.
  7. Compare the measured current with the stated lamp rating as an observation; do not force an Ohm-law match using an invented resistance.

Notebook: Label made parts and note any changed dimension. A short labeled sketch is enough; do not write an essay.

Test · 15 minutes · Test and inspect

  1. Every current reading includes unit and supervised series connection. No student experiments with meter sockets under power.
  2. Detector works after meter removal; original loop is fully restored.

Notebook: Copy the specified trial table; include each pass/fail or measured value and the change made.
