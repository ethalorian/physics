P3 · 07 · Add Guide Rails and Retest the Sled

Name: __________________ Date: __________ · 110 minutes

Why this job?

A controlled redesign changes one feature. Guide rails may improve alignment but can add friction; the test decides whether the change helps.

Daily kit · one crew

Each student: tape measure, pencil and graph notebook. Per crew: ruler, scissors and masking tape. Baseline sled/data, two 3 × 1-in card strips, 18 in tape, same cargo and stopwatch.

Finished means

  1. A tested rail revision, retained or removed with an evidence-based reason.
  2. Before/after times, clearances, rates and annotated revision drawing.

Measure · 15 minutes · Measure and mark

  1. At START and DELIVERY, mark the sled’s side-edge positions on the base.
  2. Offset each guide face 1/8 in outward from the widest side position. Start each 3-in rail level with the actuator-side deck edge at START; its length covers the 2-in deck plus 20-mm stroke.

Notebook: Feature | required value | actual value | units | datum/endpoints. Keep repeat readings.

Plan · 15 minutes · Read the plan and work the math

  1. Draw both rails on revision B top view; keep revision A visible. Label 1/8-in side clearance.
  2. Copy baseline mean time; prepare three new trials using the identical five-cycle definition.

Notebook: Use the named sketch/table in the directions. Label views, dimensions, units and revision.

Worked example · practice values

These supplied values teach the method. Build from today’s required plan dimensions; record your own actual test data.

  1. In a supplied comparison, average speed increases from 12 cm/s to 15 cm/s. Calculate the percentage increase relative to the original speed.
  2. Speed changes from 12 to 15 cm/s: (15 − 12)/12 × 100 = 25% increase.
  3. For time over a fixed distance, a shorter time is better; label the metric before calculating percent change.

Build along · one move at a time

Maker acts. Checker compares with the plan. Swap at the pause. Use the complete numbered directions below.

Stop & show

Point to both clearances. Show the original and revised times for the same delivery task.

Make · 45 minutes · Numbered bench directions

  1. Cut/fold both rails into L sections.
  2. Tape horizontal legs to the base outside the moving path; vertical legs face the sled sides. Keep tape edges off the sliding deck.
  3. Move input slowly through the full stroke and return. The deck must not be pinched at either endpoint.
  4. If a rail rubs, move that rail outward just enough to restore at least 1/8-in clearance; record its final location.
  5. Run three valid five-cycle trials using the same cargo, endpoint marks and timing method as day 6.
  6. Calculate mean time and percent time change relative to baseline. Record any cargo escape or missed endpoint separately.
  7. Keep rails if they improve control without harmful binding. If worse, peel them off, restore revision A and record the rejected design.

Notebook: Label made parts and note any changed dimension. A short labeled sketch is enough; do not write an essay.

Test · 15 minutes · Test and inspect

  1. Only guide-rail configuration changes intentionally; load, travel and cycle count stay fixed.
  2. Do not report improvement from an incomplete or faster-but-missed delivery. A worse result is usable engineering evidence.

Notebook: Copy the specified trial table; include each pass/fail or measured value and the change made.
