Name: __________________ Date: __________ · 110 minutes

Why this job?

Construction inspection checks a list of specified features. A model can look finished while its views or opening dimensions disagree.

Daily kit · one crew

Each student: tape measure, pencil and graph notebook. Per crew: ruler, scissors and masking tape. Completed room, top/south elevation/layer-detail drawings, person/table tokens and test records.

Finished means

  1. Inspected room model and coordinated three-view/detail set.
  2. Each student has an individual scale, tape and plan-reading check.

Brief · 10 minutes · Today’s exact job

  1. Why this job: Construction inspection checks a list of specified features. A model can look finished while its views or opening dimensions disagree.
  2. Required today: Hand over the room model with a working door, removable roof/panel and matching drawings.
  3. Look at the supplied labeled drawing. Find the finished object or test setup before starting.
  4. Read the kit list. Take the listed continuing project out of storage; name missing items before beginning.

Notebook: Title/date; one sentence naming today’s exact object and its purpose.

Measure · 15 minutes · Measure and mark

  1. Each student measures the 8-in width, 6-in depth, 4-in height and door’s 1-in west offset.
  2. Convert one actual model dimension back to feet using ÷ 1/2 in per ft; label it a represented dimension.

Notebook: Feature | required value | actual value | units | datum/endpoints. Keep repeat readings.

Plan · 15 minutes · Read the plan and work the math

  1. Set up inspection table: feature | required | measured | difference | action.
  2. Required checks: shell ±1/8 in; door width/height/offset ±1/16 in; door swing 90 degrees; roof/panel removable.

Notebook: Use the named sketch/table in the directions. Label views, dimensions, units and revision.

Worked example · practice values

These supplied values teach the method. Build from today’s required plan dimensions; record your own actual test data.

  1. A model dimension measures 7 1/2 in. At 1/2 in = 1 ft, what full-size dimension does it represent?
  2. 7 1/2 model inches ÷ (1/2 in per ft) = 15 ft.
  3. The result describes the intended full-size dimension, not a physically validated full-size building.

Build along · one move at a time

Maker acts. Checker compares with the plan. Swap at the pause. Use the complete numbered directions below.

Stop & show

Point from one plan dimension to its feature on the model. Show the check and any correction.

Make · 45 minutes · Numbered bench directions

  1. Exchange model and drawing set with another crew.
  2. Inspect dimensions without changing their model. Move the person token from entrance to both tables.
  3. Remove and replace roof and insulation panel three times each; record catches or damage.
  4. Return inspection sheet. Owners repair one reported mismatch, or independently recheck a dimension if no fault was found.
  5. Update drawings to match the repair. Give a one-minute demonstration of door, route and removable pieces.
  6. Show your teacher one independent measurement and one scale conversion. Store model and test-frame together.

Notebook: Label made parts and note any changed dimension. A short labeled sketch is enough; do not write an essay.

Test · 15 minutes · Test and inspect

  1. Every specified dimension has a recorded value; functional tests have explicit pass/fail.
  2. Thermal claim cites actual cup data and does not claim a code rating or full-size building safety.

Notebook: Copy the specified trial table; include each pass/fail or measured value and the change made.

Explain · 10 minutes · Show the finished work

  1. Put these on the bench: Inspected room model and coordinated three-view/detail set.
  2. Each student has an individual scale, tape and plan-reading check.
  3. Complete the independent transfer problem below. These supplied numbers are practice values; they do not change the required build dimensions.
  4. At 1/2 in = 1 ft, an opening measures 1 3/4 in in the model. What real width does it represent? Identify whether opening width is read from plan, elevation, or both when dimensioned.
  5. Save one short individual answer with units, working and notebook page/date. Show the teacher your own physical measurement and plan interpretation. Store the labeled project and return shared supplies.

Notebook: Individual transfer calculation with units + page/date containing the practical evidence.
