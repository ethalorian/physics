P1 · 04 · Assemble and Reinforce the Supply Tray

Assemble the durable tray and add four folded corner reinforcements; compare it with the folder prototype.

Name: __________________ Date: __________ · 110 minutes

Why this job?

A stronger joint consumes material and time. You will make that change deliberately and calculate a transparent classroom material cost.

Daily kit · one crew

Each student: tape measure, pencil and graph notebook. Per crew: ruler, scissors and masking tape. Seven durable parts from day 3, prototype, four 2 × 2-in card squares, the same test supplies, and a measured 48-in tape allowance.

Finished means

  1. An assembled durable three-bay tray with four angle brackets; prototype retained.
  2. Notebook: before/after retrieval table, finished dimensions and actual tape-use calculation.

Brief · 10 minutes · Today’s exact job

  1. Why this job: A stronger joint consumes material and time. You will make that change deliberately and calculate a transparent classroom material cost.
  2. Required today: Assemble the durable tray and add four folded corner reinforcements; compare it with the folder prototype.
  3. Look at the supplied labeled drawing. Find the finished object or test setup before starting.
  4. Read the kit list. Take the listed continuing project out of storage; name missing items before beginning.

Notebook: Title/date; one sentence naming today’s exact object and its purpose.

Measure · 15 minutes · Measure and mark

  1. Measure and mark the four 2 × 2-in squares and their 1-in center folds.
  2. Record starting tape allowance 48 in; measure unused tape at the end. Use the final cut-list dimensions, not the raw blank sizes, for area.

Notebook: Feature | required value | actual value | units | datum/endpoints. Keep repeat readings.

Plan · 15 minutes · Read the plan and work the math

  1. Copy revision B onto the top view and mark the four reinforced outside corners.
  2. Set up a material table: card area (in²), tape used (in), tape used ÷ 12 (ft). The worked example uses supplied classroom prices, not actual store prices.

Notebook: Use the named sketch/table in the directions. Label views, dimensions, units and revision.

Worked example · practice values

These supplied values teach the method. Build from today’s required plan dimensions; record your own actual test data.

  1. A build uses 0.50 sheet at a supplied classroom price of $2.40 per sheet and 3 ft of tape at $0.10 per foot. Calculate the cost of the material consumed.
  2. 0.50 sheet × $2.40/sheet + 3 ft × $0.10/ft = $1.50.
  3. This is material consumed. Buying one whole sheet would cost $2.40 before tape or other supplies.

Build along · one move at a time

Maker acts. Checker compares with the plan. Swap at the pause. Use the complete numbered directions below.

Stop & show

Point to a bracket. Show before/after retrieval counts and the actual tape used from the 48-in allowance.

Make · 45 minutes · Numbered bench directions

  1. Tape F/R to B, then fit and tape E1/E2 using the checked part lengths.
  2. Put D1/D2 left faces on their marked lines; tape bottoms and ends.
  3. Fold each reinforcing square 90 degrees along its centerline.
  4. Fit one bracket vertically inside each outer corner. Tape one leg to the long wall and one to the end wall; leave the bottom against B.
  5. Move the same supplies from the prototype into the same labeled bays.
  6. Run the retrieval test on both versions. If a reinforced corner catches an object, trim only the projecting tape and retest.
  7. Measure remaining tape and calculate used length. Label the durable tray revision B and retain prototype A.

Notebook: Label made parts and note any changed dimension. A short labeled sketch is enough; do not write an essay.

Test · 15 minutes · Test and inspect

  1. For each version, remove/return each supply type three times. Count snags and loose joints using the same operator and objects.
  2. Measure outside width and one clear bay. Check that reinforcement did not block the assigned objects.

Notebook: Copy the specified trial table; include each pass/fail or measured value and the change made.

Explain · 10 minutes · Show the finished work

  1. Put these on the bench: An assembled durable three-bay tray with four angle brackets; prototype retained.
  2. Notebook: before/after retrieval table, finished dimensions and actual tape-use calculation.
  3. Complete the independent transfer problem below. These supplied numbers are practice values; they do not change the required build dimensions.
  4. Your build consumes 3/4 sheet at a classroom price of $2.40 per sheet and 4 ft of tape at $0.10/ft. Find consumed-material cost and the purchase cost if you must buy one sheet plus that tape.
  5. Save one short individual answer with units, working and notebook page/date. Show the teacher your own physical measurement and plan interpretation. Store the labeled project and return shared supplies.

Notebook: Individual transfer calculation with units + page/date containing the practical evidence.
