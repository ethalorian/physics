The Unit 1 color code
Every page in Unit 1 uses the same six colors, and each color always means the same thing. First, color each swatch below with your own pencil or marker. Then, whenever a page asks you to color, choose the color by what the thing is.
HOW MOTION CHANGES
Use these for acceleration: what the change in velocity does
GREEN
Speeding up. v and a have the same sign; motion dots spread apart. Ex: a car leaving a green light, the trend line on an a–F graph.
RED
Slowing down. v and a have opposite signs; motion dots crowd together. Ex: braking, a ball rising before it peaks.
YELLOW
Steady or balanced. a = 0 and net force = 0, whether the object is moving or at rest. Ex: cruise control, a hanging sign.
QUANTITIES
Use these for what you measure and draw
BLUE
Position and displacement. Where it is and how far it ended up. Ex: start and finish dots, displacement arrows, area under a v–t line.
PURPLE
Velocity. How fast and which way. Ex: velocity arrows, v–t lines, the slope of an x–t graph.
ORANGE
Every force. Weight, normal, friction, tension, and pushes are all orange, so label each one W, N, f, T, or F. Draw net force as a thick orange arrow.
TWO THINGS, SAME COLOR?
Keep the color and change the line:
solid = measured or actual dashed = predicted, resultant, or a part stripes = negative area light shade = a range
PENCIL · EVERYTHING ELSE
Axes, labels, data points, reference points, the path for distance, and anything you cross out stay in pencil.
Sorting evidence or questions? Use the letters the page gives (E, I, Q, P, D), not colors.
