Vector addition and decomposition
LEARNING TARGET · S2
I can join arrows tip to tail and split an arrow into parts using sine and cosine.
A · KEY VOCABULARY
Vector
A quantity with size and direction, drawn as an arrow.
Tip-to-tail
Start each arrow where the last one ends. Do not turn or stretch it.
Component
The east–west or north–south part of a vector.
Resultant
The overall arrow from the first start to the final finish.
B · KEY EQUATIONS + SIGNS
Rx = Ax + Bx · Ry = Ay + By
|R| = √(Rx² + Ry²)
θ = tan⁻¹(Ry ÷ Rx)
parts: V cos θ (next to θ) · V sin θ (opposite)

D · WORKED EXAMPLE
