Acceleration
LEARNING TARGET · R4
I can use velocity–time data to find how fast velocity changes.
A · KEY VOCABULARY
Acceleration
The rate velocity changes: how much velocity is gained or lost each second.
Speeding up
v and a have the same sign. Gaps between equal-time dots grow.
Slowing down
v and a have opposite signs. Braking is acceleration too.
Turning
A direction change is a velocity change, even at steady speed.
B · KEY EQUATIONS + UNITS
a = Δv ÷ Δt
v = v0 + a t
a
m/s² (“m/s, every second”)
g
≈ 9.8 m/s² (free fall)
C · COLOR IT · READ THE GAPS
Equal time between dots.
1 · GREEN
Speeding up: gaps grow
2 · RED
Slowing down: gaps shrink
3 · YELLOW
Steady: a = 0
D · WORKED EXAMPLE
A cart’s velocity changes from 0 to 8 m/s in 4 s. Find its acceleration.
GIVEN
vi = 0 m/s
vf = 8 m/s
Δt = 4 s
EQUATION
a = Δv ÷ Δt
WORK
Δv = 8 − 0 = 8 m/s
a = 8 ÷ 4
ANSWER
2 m/s²
gains 2 m/s each second
