READING WINDOW

10 points independently · 5 with help
Field guide: how to read a scale
  1. Check the unit and count the spaces in one unit.
  2. Align zero with the starting edge. Keep the tape straight.
  3. Read the whole number, then add the fraction of a unit.
  4. If the start is not zero, subtract: end − start = length.

A long tick is a landmark. A short tick is still a real graduation. Read directly above the edge to avoid parallax.
